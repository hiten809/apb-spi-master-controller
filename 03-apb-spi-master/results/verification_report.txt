5. APB REGISTER AND ERROR TESTS
-------------------------------
The APB test checks:
  - CTRL reset value and read/write behavior
  - STATUS reset and FIFO status values
  - Four-entry TX FIFO filling
  - TX FIFO full indication
  - Rejection of a fifth TX FIFO write
  - Write to read-only STATUS register
  - Read from write-only TXDATA register
  - RXDATA read while RX FIFO is empty
  - Access to an unmapped register address

Functional coverage counters:
  Successful writes: 5/5
  Successful reads:  4/4
  Expected errors:   5/5

  PASS: APB registers, TX FIFO overflow, and APB error checks

6. RX FIFO FULL / PAUSE / RECOVERY TESTS
----------------------------------------
The RX FIFO full test was run independently in SPI modes 0, 1, 2,
and 3.

Each mode verifies:
  - RX FIFO reaches full state after four received bytes
  - SPI engine becomes idle while RX FIFO is full
  - A queued fifth transfer does not start while RX FIFO is full
  - Reading one RX byte permits the fifth transfer to resume
  - RX FIFO returns to full state after the fifth response
  - All five received bytes are read in the expected order
  - RX FIFO reports empty after draining

Coverage per SPI mode:
  RX full events:       2/2
  Pause checks:         1/1
  Resume events:        1/1
  RX bytes verified:    5/5

  PASS: RX FIFO full/pause/recovery, SPI modes 0, 1, 2, and 3
